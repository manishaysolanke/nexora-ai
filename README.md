# Nexora AI

A responsive Modern SaaS product website created as a JIVIQ testing environment.

## Files

- `index.html` — complete website structure/content
- `styles.css` — responsive styling and animations
- `script.js` — navigation, smooth scrolling, FAQ accordion, reveal animations, and demo contact form

## Run locally

Open `index.html` in a browser.

For a local development server, from this folder run:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Important

The contact form is intentionally front-end only for testing. It does not send email or store submissions yet.

When the site is deployed, the JIVIQ integration can be added after the basic site is live.
